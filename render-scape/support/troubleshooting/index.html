Render Scape guide

A few quick checks.

Start with the symptom you’re seeing.

Overview Support FAQ Privacy License
The wallpaper is not moving

Check Pause/Resume, Reduce Motion, and Power & Metrics. Connect to power if you are on battery. Live rendering requires Apple Silicon; Intel uses still images.

The scene feels too active

Lower the scene amount or speed, select Eco, pause animation, or choose a static photo.

My photo looks cropped

Images fill the display without stretching, so their edges may be cropped. Try an image whose shape matches your display.

The widget status seems out of date

Open Render Scape and check status sharing. macOS controls widget refresh timing; widget values are snapshots, not a continuously live display.

How do I remove the widget?

Control-click the widget itself and choose Remove Widget. This does not reset your settings or stop the wallpaper.

I still see the old Matrix Rain name

Some earlier builds and macOS widget entries use the previous Matrix Rain name. Include the version and where you see the name when contacting support.
